# AutoScroll · Chrome 页面往返滚动

在 Chrome 中配置一组网页，自动按顺序滚到底，再逆序滚回顶部。支持变速滚动、定时/随机停顿、停顿后随机反向回滑、暂停/继续和循环。运行不需要服务器、Node.js 或额外账号。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **`extension` 文件夹**，不是项目根目录。
4. 在扩展菜单中固定「AutoScroll · 页面往返滚动」，点击图标打开控制面板。

支持 Chrome 120 及以上版本。如果使用发布压缩包，先解压，再选择其中的 `extension` 文件夹。更新文件后，在扩展管理页点击扩展的刷新按钮。

## 使用

1. 在「页面队列」中每行填写一个完整的 `https://` 或 `http://` 地址，也可点击「＋ 当前页面」添加浏览器当前地址。
2. 设置基准速度（1–5000 像素/秒，默认 160），以及循环次数，或勾选「无限循环」。实际滚动会平滑加减速，在基准速度的约 60%–140% 之间变化。
3. 在「滑动停顿」中选择连续滚动、定时停顿或随机停顿。随机模式可设置「最短停顿」「最长停顿」；选择停顿模式后，还可设置停顿后的反向回滑距离范围。
4. 点击「开始滚动」。运行期间可调整基准速度，也可点击「暂停」「继续滚动」或「停止」。控制面板可向下滚动以查看全部设置。

以三个页面为例，一轮是：

```text
A 顶部 → A 底部
         B 顶部 → B 底部
                  C 顶部 → C 底部
                  C 底部 → C 顶部
         B 底部 → B 顶部
A 底部 → A 顶部
```

每个配置项使用一个新标签页。扩展滚完当前页后才打开下一页；回程切换到已有标签。循环复用同一组标签，不重复开页或刷新。重复地址也按独立队列项处理。

- **一轮**：全部页面依次到底，再全部逆序回顶；不是仅下滚一遍。
- **暂停**：停在当前位置，并保留当前滚动、自动停顿或回滑的剩余进度；继续时接着执行。
- **停止**：结束任务，保留已打开的标签与已保存配置。再次开始会建立一组新标签。
- **关闭面板**：任务继续运行。再次点击扩展图标可查看进度或停止。
- **保存配置**：仅保存配置；点击「开始滚动」也会自动保存。
- 运行期间可修改基准速度；调整地址、停顿模式、回滑范围、循环次数和高级设置前，请先停止任务。

## 变速、停顿与回滑

所有模式均采用平滑变速，包括主方向滚动、反向回滑及恢复原方向的过程。「基准速度」用于控制整体快慢，不是固定匀速。

| 模式 | 行为 |
| --- | --- |
| 连续滚动 | 持续变速滚动至页面边缘，不插入中途停顿。旧配置默认使用此模式。 |
| 定时停顿 | 每次滑动 X 秒，停顿 Y 秒。默认 5 秒 / 2 秒，均可设置为 0.1–3600 秒。 |
| 随机停顿 | 每段独立随机确定滑动 1–600 像素，随后在设置的最短/最长时间之间独立随机停顿；默认 1–20 秒，距离和秒数均为整数。 |

随机停顿的最短、最长时间均支持 **1–3600 秒**，最短时间不能大于最长时间。例如设置为 5 和 30，每次会随机停顿 5–30 秒；两者均设为 3 时，每次固定停顿 3 秒。配置会保存到本机，旧配置自动使用 1–20 秒。修改范围前请先停止当前任务。

每次中途自动停顿结束后，先向当前主方向的反方向随机回滑，再恢复原方向。例如：向下滑动 → 停顿 → 向上回滑 → 向下继续。默认回滑范围为 **1–100 像素**，最小值、最大值均可在 1–600 像素内设置；两者相同时使用固定回滑距离。

回滑距离受页面可用空间限制。回滑后先回到停顿前的位置，再计入下一段主方向滑动的时间/距离，避免短距离配置导致一直原地往返。到顶/到底时优先按边缘等待规则切换方向或页面，不再插入中途停顿和回滑。

控制面板显示「停顿中」倒计时、「反向回滑」和恢复原方向的状态。自动停顿、回滑期间也可手动暂停、继续或停止；停止后不会被旧计时器重新启动。

从旧版更新：先停止当前任务，在 `chrome://extensions` 刷新扩展，再重新打开控制面板。

## 更多设置

**到顶 / 到底等待**：默认 1.5 秒，范围 0.3–10 秒。到达边缘后等待页面稳定，若期间追加内容，会继续下滚。延迟加载较慢时可适当增加此值。

**滚动容器**：留空时优先滚动整个文档；如果文档无法滚动，会自动选择最大的可见滚动区域。遇到带独立内容面板的网站，可指定 CSS 选择器，例如 `.main-content` 或 `#scroll-container`。此选择器用于队列中的所有页面；未匹配时会显示错误并停止任务。

## 适用范围

- 用于普通 HTTP/HTTPS 网页，共享当前 Chrome 的登录状态。需要登录的网站请提前登录。
- Chrome 内部页面、Chrome 网上应用店、内置 PDF 阅读器、跨域 iframe 内部区域等受浏览器限制，无法滚动。
- 无限加载内容、没有真正底部的页面会持续向下滚动，可手动停止。
- 保持 Chrome 可运行且系统不休眠。后台标签、最小化窗口和系统节能可能使滚动变慢；恢复时不会突然跳过大量内容。
- 当前任务的标签被关闭、刷新或跳转后会显示错误。检查地址和页面后重新开始。
- 配置保存在本机。运行状态在当前浏览器会话保留，重启 Chrome 后不会自动继续任务。
- 默认从页面顶部开始下滚，从页面底部开始上滚。自动识别不适用于所有复杂网页，必要时使用滚动容器设置。

## 权限与数据

`storage` 保存配置及会话进度；`tabs` 管理队列标签及读取「当前页面」地址；`scripting` 在任务页面执行滚动；`alarms` 检查加载状态并处理后台唤醒。HTTP/HTTPS 主机权限用于滚动用户配置的页面。脚本仅注入任务目标页，没有服务器、统计、数据上传或远程代码。

实现参考：[Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[扩展后台生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。

## 开发与验证

安装扩展不需要这些步骤；以下仅用于开发。需要 Node.js 20+。

```bash
npm ci
npm test
npm run check
npx playwright install --no-shell chromium
npm run test:browser
npm run package
```

浏览器测试使用临时配置目录、独立 Chromium 和本地测试网页，不操作日常 Chrome 的标签或账号。真实加载扩展验证往返顺序、真实滚动位置、循环、动态加载、嵌套与缩放容器、停顿、双向回滑、暂停/继续、调速、停止、后台恢复及配置界面。界面截图写入 `artifacts/control-panel.png`。

`npm run package` 使用系统 `zip` 命令生成 `dist/autoscroll-1.2.0.zip`，仅包含扩展与说明，不包含测试依赖。

```text
extension/        可直接加载的扩展
  manifest.json   Chrome 扩展声明
  model.js        配置校验与往返状态机
  background.js   标签调度、控制与会话状态
  content.js      页面滚动与边缘检测
  popup.*         中文控制面板
tests/            单元与真实浏览器测试
scripts/          检查与打包脚本
```
