# AutoScroll 设计

实现为无构建步骤的 Chrome Manifest V3 扩展，使用浏览器已有登录状态。独立脚本需要额外的浏览器启动和环境配置，因此默认选择扩展。源代码放在 `extension/`，可直接通过 Chrome 开发者模式加载。

## 行为

- 用户输入多行 HTTP/HTTPS 地址，顺序保留，重复地址也作为独立页面处理；可添加当前标签页地址。
- 第一轮依次新建 A、B、C 标签页并从顶部滚到底，随后切回已有标签，按 C、B、A 从底部滚到顶部。这算一轮。后续循环复用标签，不重新加载。
- 速度为 1–5000 像素/秒，默认 160；运行中可调整。循环次数默认 1，0 表示无限。
- 边缘等待默认 1500 毫秒，等待期间如果页面增高，继续下滚，直到边缘稳定。真正无限加载的页面不会自动结束，用户可以停止。
- 开始、暂停、继续、停止；暂停保留位置；停止保留已打开的标签和配置。
- 控制面板显示方向、当前页面、页面进度、完成轮数和错误。关闭弹窗不影响运行。
- 默认滚动文档，文档不可滚动时选择最大的可见滚动容器。高级配置允许指定 CSS 选择器。
- 加载超时、目标标签被关闭、导航到其他页面或脚本执行失败时停止当前任务并显示原因，不静默跳过。

## 结构

`model.js` 处理配置校验和纯函数往返状态机；`background.js` 串行处理控制消息、标签生命周期和运行状态；`content.js` 执行当前段的逐帧滚动；`popup.*` 提供中文控制面板。

配置存在 `chrome.storage.local`，当前运行存在 `chrome.storage.session`。页面进度消息触发后台状态更新，带任务/段标识排除过期消息。后台事件监听器在模块顶层注册；恢复后读取会话状态。Chrome 重启不自动恢复任务。

仅声明所需的 storage、scripting、tabs、alarms 和 HTTP/HTTPS 主机权限。脚本仅在用户启动的目标标签注入，无服务器、数据上传或远程代码。

## 验证

Node 单元测试验证地址和数值校验、三页往返、单页往返、有限及无限循环。Playwright 在独立 Chromium 配置中加载真实扩展，使用本地页面验证标签顺序、真实滚动位置、暂停/恢复、速度调整、动态增高、短页面、停止和错误。

## 边界

只处理普通 HTTP/HTTPS 页面，不支持浏览器内部页面、扩展商店、PDF 阅读器和跨域 iframe 内部。浏览器或操作系统休眠会使滚动暂停或变慢；后台标签节流不会用大幅跳跃补偿。无需为运行扩展安装 Node；Node 与 Playwright 仅用于开发验证。
